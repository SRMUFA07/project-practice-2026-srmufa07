# Отчёт по изучению больших языковых моделей (LLM)

## Цель изучения

В рамках проектной практики были изучены современные большие языковые модели (LLM), их архитектура, способы применения в разработке программного обеспечения, а также методы эффективного взаимодействия с искусственным интеллектом.

Основные цели изучения:

- изучить архитектуру Transformer и принципы работы LLM;
- ознакомиться с современным состоянием NLP;
- изучить практическое применение LLM в программировании;
- освоить основы prompt engineering;
- изучить применение RAG и AI-агентов;
- научиться использовать LLM для генерации кода и документации.

## Полученные знания

Было изучено, что современные LLM основаны на архитектуре Transformer, которая использует механизм attention для анализа контекста текста.

Также были изучены:

- различия между обучением и инференсом модели;
- принцип предсказания следующего токена;
- хранение параметров модели;
- причины возникновения галлюцинаций;
- ограничения контекстного окна.

Дополнительно были изучены этапы обучения моделей:

1. Pre-training  
   Обучение модели на огромных объёмах текстовых данных.

2. Fine-tuning  
   Дообучение модели под конкретные задачи.

---

Изучение архитектуры Transformer позволило лучше понимать:

- как работают современные чат-боты;
- почему LLM допускают ошибки;
- как правильно формулировать запросы;
- как использовать ограничения модели в реальных проектах.

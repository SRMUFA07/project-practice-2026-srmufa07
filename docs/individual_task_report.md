# Individual Task Report

## Выданное задание


Идея в том, что мы указываем официальные сайты, ссылки и все решения которые у них есть.

Задача: сверстать такую страницу в `HTML`, `CSS`.

## Проделанная работа

### 1. Структура проекта приведена в порядок
- Стили вынесены из `index.html` в отдельный файл `css/style.css`.
- Логика вынесена в `js/`:
  - `js/main.js` — переход с карточек каталога на страницу компании.
  - `js/company.js` — рендер страницы компании по параметру `?c=`.
  - `js/catalog-data.js` — единый каталог данных по компаниям и продуктам.
- Медиафайлы размещены в `image/` (`logo.png`, `search.png`, логотипы компаний в `.jpeg`).

### 2. Реализована главная страница каталога
- Сверстана страница `index.html` по макету с сеткой карточек компаний.
- Для каждой карточки указаны:
  - логотип компании;
  - название;
  - ссылка «Все модели».
- Карточки кликабельны: переход на отдельную страницу компании.

### 3. Реализована отдельная страница компании (`company`)
- Создана `company.html`.
- Добавлены:
  - шапка с навигацией;
  - крупный информационный блок о компании (лого, краткая похвала, описание);
  - карточки продуктов/моделей с описанием и официальными ссылками.
- Контент подставляется динамически из `js/catalog-data.js` через `js/company.js`.

### 4. Заполнен каталог компаний и продуктов
- Для каждой компании добавлено минимум 3 продукта.
- Для каждого продукта указаны:
  - название;
  - краткое описание;
  - ссылка на официальный ресурс.
- Добавлены смысловые теги по содержанию карточек (например: `Чат-бот`, `API`, `Видео`, `Поиск`, `Код`, `Платформа`, `Enterprise`, `Модели`).

### 5. Доработки интерфейса
- Обновлены ссылки в шапке:
  - Главная: `https://aiworkshop.su/`
  - Лента: `https://aiworkshop.su/feed`
  - ТГ-канал: `https://t.me/AI_officina`
- Шапка закреплена на десктопе и корректно адаптирована под мобильные устройства.
- На мобильной версии:
  - шапка не фиксируется;
  - на странице компании скрывается крупное лого в hero-блоке.
- Для логотипов в карточках исключено обрезание: применены белый фон и масштабирование через `object-fit: contain`.

## Результат и где размещено

Все результаты размещены в src:
- `index.html` — главная страница каталога.
- `company.html` — страница компании с продуктами.
- `css/style.css` — все стили и адаптив.
- `js/main.js` — навигация по карточкам.
- `js/company.js` — рендер контента страницы компании.
- `js/catalog-data.js` — данные компаний, продуктов, ссылок и тегов.
- `image/` — логотип сайта, иконка поиска, логотипы компаний (`.jpeg`).
- `individual_task_report.md` — данный отчет.
